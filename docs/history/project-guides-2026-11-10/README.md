# Archived standalone project guides

These sources preserve the earlier satellite guide, tank-dome lesson cards, option-picking UI,
Claude review briefs and the first equipment studies. They are not mounted by the hub.
The hub now links to `satellite/` and `dome/`, both using the existing course shell.

Satellite build methods and Structure comparisons moved into its unit notes. The new closing
unit covers payload and integration without claiming labs exist. The tank dome has four units,
four checked numeric labs, notes for all eleven shop stations, numeric practice and the four
shop-floor judgement cases as worked examples. The equipment geometry is reused inside the
course scene through an adapter; it does not create another project-specific page or header.

Old browser course and guide records are left in place. Legacy application data remains covered
by backup compatibility. The abandoned guide's local learning record is preserved in its browser
key and is not treated as standard course mastery.
