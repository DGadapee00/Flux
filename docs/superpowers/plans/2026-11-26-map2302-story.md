# MAP 2302 story bridges Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a unit route, Part bridges and section openers to the four MAP 2302 notes files.

**Architecture:** Text-only edits to `courses/map2302/src/notes/content/*.html`, guarded by three
new assertions in `courses/map2302/scripts/notes-check.mjs`.

**Tech Stack:** HTML notes, KaTeX, Node check scripts.

**Spec:** `docs/superpowers/specs/2026-11-26-map2302-story-design.md`

## Global Constraints

- The Voice rules in `AGENTS.md`: short plain sentences, no em dashes, no filler words.
- Original text. No numbers added. Existing paragraphs, math and examples stay.
- No CSS changes.

## Review Focus

- A bridge that only restates the section title. Each one must name a gap or a payoff.
- A section opener that repeats the existing first paragraph.
- TeX in a bridge that does not typeset. notes-check already typesets every formula.
- Section openers inside a Part whose bridge already says the same thing.
- Layout at 390 px: longer ledes and part bridges must not clip.
