Part I

Feedback

1The inverting amplifier

An op amp multiplies the difference between its inputs by a huge gain \(A\), from \(10^4\) to \(10^6\), which varies from part to part and with temperature. Feedback trades that gain for one set by resistors.

Derivation

Ground the + input, run \(R_1\) from the input to the − input and \(R_f\) from the output back to it. The op amp gives \(v_\text{out} = -A v_-\), and the current law at \(v_-\) is \((v_\text{in} - v_-)/R_1 + (v_\text{out} - v_-)/R_f = 0\). Eliminating \(v_-\),

\[ G = \frac{v_\text{out}}{v_\text{in}} = \frac{-R_f/R_1}{1 + (1 + R_f/R_1)/A} \ \longrightarrow\ -\frac{R_f}{R_1} \quad \text{as } A \to \infty. \]

Then \(v_- = -v_\text{out}/A \to 0\): the − input sits at ground without being connected to it, a virtual ground. Every bit of current through \(R_1\) goes on through \(R_f\).

Worked example · a gain of ten

\(R_1 = 10\) kΩ, \(R_f = 100\) kΩ. With \(A = 10^5\) the gain is \(-10/(1 + 11 \times 10^{-5}) = -9.999\). With an op amp a hundred times worse, \(A = 10^3\), it is \(-10/1.011 = -9.891\), only 1.09% short. For a 0.5 V input, \(v_-\) swings by 4.95 mV.

Common mistake

Thinking the op amp's own gain sets the circuit's gain. It only has to be far larger than \(1 + R_f/R_1\); the resistors do the rest.

2The rails

The output comes from the supply, so it cannot go past it. Most op amps stop a volt or two inside each supply rail.

Derivation

The output follows \(G v_\text{in}\) only while \(|G v_\text{in}| \le V_\text{sat}\), so the largest input that stays linear is \(V_\text{sat}/|G|\). Past it the output is pinned at \(\pm V_\text{sat}\), the op amp no longer has gain to spare, and \(v_-\) leaves zero: the virtual ground fails.

Worked example · 2 V in

The gain of ten on ±15 V supplies, with the output reaching 13.5 V. The largest input is \(13.5/10 = 1.35\) V. A 2 V input would ask for 20 V; the output flattens at 13.5 V for the top of every swing.

Key idea

Within the rails, feedback makes an op amp circuit exactly what its resistors say. At the rails, the rules stop.
