Methods of analysis

Two systematic ways to turn any resistive circuit into a set of linear equations, and how to tell which one needs fewer.

Part I

Two methods

1Node voltages

Pick one node as ground, at 0 V. Give every other node an unknown voltage. Each branch current then follows from Ohm's law, and Kirchhoff's current law at each node gives one equation.

Derivation

A branch from node \(a\) to node \(b\) with resistance \(R\) and a source \(V\) pushing from \(a\) to \(b\) carries \(i = (v_a - v_b + V)/R\). Set the currents leaving each node to zero:

\[ G\,\mathbf v = \mathbf i_s, \qquad G_{kk} = \sum_{\text{at } k}\frac{1}{R}, \qquad G_{kj} = -\sum_{\text{between } k, j}\frac{1}{R}. \]

There is one equation for each node except ground.

Worked example · two rails

Four branches join a bottom rail (ground) to a top rail: 10 V with 2 Ω, a 4 Ω resistor, 6 V with 3 Ω, and a 6 Ω resistor. One unknown, the top rail's voltage \(v\):

\[ \frac{v - 10}{2} + \frac{v}{4} + \frac{v - 6}{3} + \frac{v}{6} = 0 \quad\Longrightarrow\quad v = \frac{10/2 + 6/3}{1/2 + 1/4 + 1/3 + 1/6} = \frac{7}{1.25} = 5.6\ \text{V}. \]

The 10 V branch then carries \((10 - 5.6)/2 = 2.2\) A up into the rail.

Common mistake

Leaving the plain resistors out of the sum. Every branch at the node carries current, sources or not.

2Mesh currents

Give every window of the drawing its own loop current. A branch shared by two windows carries the difference of their currents. Kirchhoff's voltage law round each window gives one equation.

Derivation \[ R\,\mathbf I = \mathbf v_s, \qquad R_{mm} = \sum_{\text{in } m} R, \qquad R_{mn} = -\sum_{\text{shared}} R \ \ (\text{both loops the same way round}). \]

A connected planar circuit with \(b\) branches and \(n\) nodes has \(b - n + 1\) windows, so that many equations.

Worked example · one loop

A 12 V source with its own 1 Ω, then 2 Ω, 3 Ω and 4 Ω, all in one loop. One window, one equation:

\[ (1 + 2 + 3 + 4)\,I = 12 \quad\Longrightarrow\quad I = 1.2\ \text{A}. \]

The node after the source sits at \(12 - 1.2(1) = 10.8\) V. Nodal analysis would have needed three equations.

3Choosing a method

Both methods give the same currents, because both are Kirchhoff's laws and Ohm's law. They differ in how many equations they need.

Worked example · a bridge

A 12 V source with 1 Ω feeds a bridge: 2 Ω and 3 Ω on top, 4 Ω and 2 Ω below, 5 Ω across the middle. Four nodes and six branches: three nodal equations, \(6 - 4 + 1 = 3\) mesh equations. Either way, the source delivers 3.28 A and 0.309 A crosses the middle. Change the 2 Ω at the bottom right to 6 Ω, so that \(2/4 = 3/6\), and the current across falls to zero: the bridge is balanced.

Key idea

Count first: nodes minus one, or branches minus nodes plus one. Many branches between few nodes favour nodes; long chains in few loops favour meshes.
