# Courses

One folder per course. PHY 2049, Statics, MAC 2313, and STA 3032 are imported at the commits in each folder's `SOURCE`. A course is a manifest, its labs, its problem bank, and its notes. It imports `@flux/core` and `@flux/subjects`. It does not import another course.

A project is a course in the hub's Projects group. `satellite` and `dome` use the same units, labs, notes and practice layout as the other course apps. Their former standalone guides and project shell are archived under `docs/history/project-guides-2026-11-10/`.

Each course folder has its own `PROVENANCE.md`. Course material without permission stays out.
