Functions and limits

01Functions, briefly

A function is a rule that gives each input exactly one output. The set of allowed inputs is the domain. The set of outputs it actually produces is the range. A graph passes the vertical line test when no vertical line meets it twice. That is the same statement: one output per input.

Chapter 1 of the text reviews the families this course uses: polynomials, rational functions, roots, trigonometric functions, exponentials, and logarithms. This section keeps only the three ideas the limit sections lean on: composition, inverses, and radians.

A composition feeds one function into another. \((f \circ g)(x) = f(g(x))\). Its domain is every \(x\) in the domain of \(g\) whose output \(g(x)\) lies in the domain of \(f\). Both conditions apply.

Worked example · the domain of a composition

Let \(f(x) = \sqrt{x}\) and \(g(x) = x - 2\). Then \(f(g(x)) = \sqrt{x - 2}\). The function \(g\) accepts every real number. The square root needs \(x - 2 \ge 0\). So the domain of \(f \circ g\) is \(x \ge 2\).

The other order is \(g(f(x)) = \sqrt{x} - 2\). Its domain is \(x \ge 0\). The two compositions are different functions.

An inverse undoes a function. If \(f(a) = b\), then \(f^{-1}(b) = a\). That only works when no two inputs share an output, so \(f\) must be one-to-one. On a graph, one-to-one means no horizontal line meets the curve twice.

Why

To find an inverse, write \(y = f(x)\) and solve for \(x\). The result gives the input that produced \(y\). Renaming \(y\) as \(x\) writes the inverse as a function of its own input. The graph of \(f^{-1}\) is the graph of \(f\) reflected in the line \(y = x\), because the reflection swaps every pair \((a, b)\) to \((b, a)\).

Worked example · undoing a line

Let \(f(x) = 3x - 4\). Solve \(y = 3x - 4\) for \(x\): \(x = (y + 4)/3\). So \(f^{-1}(x) = (x + 4)/3\).

Check one pair. \(f^{-1}(5) = 9/3 = 3\), and \(f(3) = 9 - 4 = 5\). The pair comes back.

Common mistake

\(f^{-1}(x)\) is not \(1/f(x)\). For the line above, \(f^{-1}(5) = 3\), while \(1/f(5) = 1/11 = 0.0909\). The \(-1\) in \(f^{-1}\) names an inverse. It is not an exponent.

The natural logarithm is the inverse of \(e^x\). So \(\ln(e^x) = x\) for every \(x\), and \(e^{\ln x} = x\) for \(x \gt 0\). The log laws are the exponent laws read backwards. Since \(e^{a}e^{b} = e^{a+b}\), taking logarithms gives \(\ln(uv) = \ln u + \ln v\).

Calculus measures angles in radians. An arc of length \(s\) on a circle of radius \(r\) subtends the angle \(\theta = s/r\). A full turn has arc \(2\pi r\), so a full turn is \(2\pi\) radians, and \(180^\circ = \pi\). Section 3 shows why this choice matters: the limit of \(\sin x / x\) is \(1\) only in radians.

Key

A function gives one output per input. An inverse exists only for a one-to-one function, and it is found by solving for the input. Angles are in radians from here on.

What it leaves out

This review skips the catalogue of function families, graph transformations, and the inverse trigonometric functions of §1.4. The text treats them in full. They return when the derivative rules need them.

02The idea of a limit

Write \(\lim_{x \to a} f(x) = L\) when \(f(x)\) can be made as close to \(L\) as we like by taking \(x\) close enough to \(a\), with \(x \ne a\). The value \(f(a)\) plays no part. It may differ from \(L\), or it may not exist.

A table of values shows the idea. Take \(f(x) = (x^2 - 1)/(x - 1)\). It has no value at \(x = 1\), because the bottom is zero there.

Worked example · a table

From the left: \(f(0.9) = 1.9\), \(f(0.99) = 1.99\), \(f(0.999) = 1.999\). From the right: \(f(1.1) = 2.1\), \(f(1.01) = 2.01\), \(f(1.001) = 2.001\). Both columns close in on \(2\). The limit is \(2\), although \(f(1)\) is undefined.

A one-sided limit restricts the approach. \(\lim_{x \to a^-} f(x)\) uses only \(x \lt a\). \(\lim_{x \to a^+} f(x)\) uses only \(x \gt a\). The two-sided limit uses both sides at once.

Why

Suppose the two-sided limit is \(L\). Then \(f(x)\) is close to \(L\) for every \(x\) near \(a\), so it is close to \(L\) for those on the left and for those on the right. Both one-sided limits are \(L\).

Now suppose both one-sided limits are \(L\). Near \(a\), the left inputs give values close to \(L\), and so do the right inputs. Together those are all the inputs near \(a\). So the two-sided limit is \(L\).

So the two-sided limit is \(L\) exactly when

\[ \lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = L. \]
Worked example · a jump

Let \(f(x) = 2\) for \(x \lt 1\) and \(f(x) = 4\) for \(x \ge 1\). Every input just left of \(1\) gives \(2\). So \(\lim_{x \to 1^-} f(x) = 2\). Every input just right gives \(4\). So \(\lim_{x \to 1^+} f(x) = 4\).

The one-sided limits disagree. The two-sided limit does not exist. The value \(f(1) = 4\) does not change that.

Worked example · a sign change

Let \(f(x) = x/|x|\). For \(x \gt 0\), \(|x| = x\), so \(f(x) = 1\). For \(x \lt 0\), \(|x| = -x\), so \(f(x) = -1\). The left limit at \(0\) is \(-1\). The right limit is \(1\). No two-sided limit exists, and \(f(0)\) is undefined.

Common mistake

The average of the two one-sided limits is not the limit. For the jump above, \((2 + 4)/2 = 3\). No input near \(1\) gives a value near \(3\). When the sides disagree, the answer is that the limit does not exist.

A limit can also fail because the values grow without bound. Near \(0\), \(1/x^2\) exceeds any number we name. We write \(\lim_{x \to 0} 1/x^2 = \infty\). That is a description of how the limit fails, not a number. The line \(x = 0\) is a vertical asymptote. For \(1/x\) the sides split: the left limit is \(-\infty\) and the right limit is \(+\infty\).

Common mistake

A table can mislead. Take \(f(x) = \sin(\pi/x)\) and test \(x = 1, 0.5, 0.1, 0.01\). Each value is \(\sin(\pi n)\) for a whole number \(n\), so each is \(0\). The table suggests a limit of \(0\).

But \(x = 2/5\) gives \(\sin(5\pi/2) = 1\), and points like it lie arbitrarily close to \(0\). The function swings between \(-1\) and \(1\) forever. No limit exists. A table is evidence. It is not a proof.

Key

A limit looks near the point and ignores the point itself. The two-sided limit exists exactly when both one-sided limits exist and agree.

In the Limits lab, the Jump and One-sided scenarios draw both sides. Move \(h\) toward zero and watch the two sample points. They approach different heights.

What it leaves out

This is the informal definition. "Close enough" has no number attached yet. Section 5 supplies one. Limits as \(x \to \infty\) wait for the graphing work in Unit 2.

03Limit laws and the 0/0 form

Most limits are found with a few laws rather than a table. Suppose \(\lim_{x \to a} f(x) = L\) and \(\lim_{x \to a} g(x) = M\). Then:

\[ \begin{aligned} \lim (f \pm g) &= L \pm M, & \lim (cf) &= cL,\\ \lim (fg) &= LM, & \lim \frac{f}{g} &= \frac{L}{M}. \end{aligned} \]

The last law needs \(M \ne 0\).

Powers and roots follow from the product law: \(\lim f^n = L^n\), and \(\lim \sqrt[n]{f} = \sqrt[n]{L}\) when the root is defined.

Why

Take the sum law. Pick a tolerance. Go close enough to \(a\) that \(f\) is within half that tolerance of \(L\), and \(g\) within half of \(M\). Then \(f + g\) is within the whole tolerance of \(L + M\), because the two errors add at most. Section 5 makes "tolerance" precise. The product and quotient laws use the same idea with more algebra.

Two limits start everything: \(\lim_{x \to a} c = c\) and \(\lim_{x \to a} x = a\). A polynomial is built from constants and \(x\) by sums and products. So the laws give \(\lim_{x \to a} p(x) = p(a)\) for every polynomial \(p\). This is direct substitution. It also works for a rational function \(p/q\), provided \(q(a) \ne 0\).

When substitution gives \(0/0\), the laws do not apply: the quotient law needs \(M \ne 0\). The form \(0/0\) says nothing about the answer. Rewrite the function first.

Worked example · a hole at 3

Find \(\lim_{x \to 3} (x^2 - 9)/(x - 3)\). Substitution gives \(0/0\). Factor the top: \(x^2 - 9 = (x - 3)(x + 3)\). For \(x \ne 3\), the quotient equals \(x + 3\). A limit never uses \(x = 3\) itself, so the two functions have the same limit. Substitute in \(x + 3\): the limit is \(6\).

Common mistake

Cancelling does not make the two functions equal. \((x^2 - 9)/(x - 3)\) is undefined at \(3\). \(x + 3\) equals \(6\) there. They agree everywhere else, and that is all a limit needs. Writing \(f(3) = 6\) is wrong.

A root in the expression calls for the conjugate. Multiplying by it turns a difference of roots into a difference of squares.

Worked example · a conjugate

Find \(\lim_{x \to 4} (\sqrt{x} - 2)/(x - 4)\). Substitution gives \(0/0\). Multiply the top and the bottom by \(\sqrt{x} + 2\). The top becomes \(x - 4\). So for \(x \ne 4\) the quotient is \(1/(\sqrt{x} + 2)\). Substitute: the limit is \(1/4 = 0.25\).

Check with a table. At \(x = 4.01\) the quotient is \(0.24984\). At \(x = 3.99\) it is \(0.25016\). Both are near \(0.25\).

Some limits cannot be rewritten into a substitution. The squeeze theorem handles them. If \(g(x) \le f(x) \le h(x)\) near \(a\), and \(g\) and \(h\) both approach \(L\), then \(f\) approaches \(L\). There is no room left for \(f\) to go anywhere else.

The standard use is \(x^2 \sin(1/x)\) at \(0\). The sine stays between \(-1\) and \(1\). So \(-x^2 \le x^2 \sin(1/x) \le x^2\). Both bounds go to \(0\). So the function does too, even though \(\sin(1/x)\) alone has no limit.

Why

Take \(0 \lt x \lt \pi/2\) on the unit circle. Three areas are nested: the triangle inside the sector, the sector, and the triangle that reaches the tangent line. Their areas are \(\tfrac12 \sin x\), \(\tfrac12 x\), and \(\tfrac12 \tan x\). So

\[ \sin x \le x \le \tan x, \]

and so

\[ \cos x \le \frac{\sin x}{x} \le 1. \]

The second form divides by \(\sin x\), then flips each fraction. As \(x \to 0^+\), \(\cos x \to 1\). The squeeze gives \(\sin x / x \to 1\). The function is even, so the left side agrees.

\[ \lim_{x \to 0} \frac{\sin x}{x} = 1, \qquad \lim_{x \to 0} \frac{1 - \cos x}{x} = 0. \]

The second limit follows from the first. Multiply by \((1 + \cos x)/(1 + \cos x)\). The top becomes \(\sin^2 x\). The quotient is \((\sin x / x) \cdot \sin x / (1 + \cos x)\). That tends to \(1 \cdot 0/2 = 0\).

Worked example · a scaled sine

Find \(\lim_{x \to 0} \sin(3x)/x\). Write it as \(3 \cdot \sin(3x)/(3x)\). As \(x \to 0\), \(u = 3x \to 0\) too, so \(\sin u / u \to 1\). The limit is \(3\). At \(x = 0.01\) the quotient is \(2.99955\).

Common mistake

The area argument measures \(x\) as arc length, which is radians. In degrees the limit changes. \(\sin(1^\circ)/1 = 0.017452\), and the limit is \(\pi/180 = 0.017453\). A calculator left in degree mode gives that wrong number.

Key

Substitute first. If the result is a number, that is the limit. If it is \(0/0\), rewrite: factor, use the conjugate, or squeeze. Then substitute again.

In the Limits lab, the Hole scenario plots \((x^2 - a^2)/(x - a)\) with an open circle at \(x = a\). The readout gives the limit \(2a\). The two probes a tiny step either side agree with it.

What it leaves out

The laws are stated, not proved in full. The product and quotient proofs are in §2.5 of the text. L'Hôpital's rule, a faster route through \(0/0\), needs derivatives and comes in Unit 3.

04Continuity

A function is continuous at \(a\) when three things hold:

  • \(f(a)\) is defined;
  • \(\lim_{x \to a} f(x)\) exists;
  • the two are equal.

So continuity is the case where substitution works. The limit laws gave it for every polynomial at every point, and for every rational function where the bottom is not zero.

A discontinuity is classified by which condition fails:

  • Removable. The limit exists, but \(f(a)\) is missing or different. Redefining one value fixes it.
  • Jump. Both one-sided limits exist, and they differ.
  • Infinite. At least one one-sided limit is \(\pm\infty\).
Worked example · a removable hole

Let \(f(x) = (x^2 - 4)/(x - 2)\), with no value at \(2\). For \(x \ne 2\) it equals \(x + 2\), so the limit at \(2\) is \(4\). The first condition fails. The discontinuity is removable: define \(f(2) = 4\), and the new function is continuous there.

Worked example · one side only

Return to the jump of Section 2: \(f(x) = 2\) for \(x \lt 1\), and \(4\) for \(x \ge 1\). Here \(f(1) = 4\) and the right limit is \(4\). So \(f\) is continuous from the right at \(1\). The left limit is \(2\). It is not continuous from the left, and not continuous at \(1\).

Common mistake

A removable discontinuity does not mean the limit fails. In the hole above the limit is \(4\). It is the function value that is missing. "The limit does not exist" belongs to the jump and the infinite cases.

Continuity survives the usual operations. Sums, differences, and products of continuous functions are continuous. So is a quotient, wherever the bottom is not zero. A composition is continuous too.

Why

Suppose \(g(x) \to b\) as \(x \to a\), and \(f\) is continuous at \(b\). As \(x\) nears \(a\), \(g(x)\) nears \(b\). Then \(f(g(x))\) nears \(f(b)\), because \(f\) is continuous there. So

\[ \lim_{x \to a} f(g(x)) = f\Bigl(\lim_{x \to a} g(x)\Bigr). \]

The limit moves inside a continuous function. This is how \(\lim_{x \to 0} \cos(\sin x) = \cos 0 = 1\) is found in one line.

Continuity on an interval means continuity at every point inside it, with one-sided continuity at a closed end. The Intermediate Value Theorem is the payoff.

Intermediate Value Theorem. If \(f\) is continuous on \([a, b]\) and \(N\) lies between \(f(a)\) and \(f(b)\), then \(f(c) = N\) for some \(c\) in \([a, b]\). A continuous graph cannot get from one height to another without passing every height between.

Worked example · a root by halving

Let \(f(x) = x^3 + x - 1\). It is a polynomial, so it is continuous. \(f(0) = -1\) and \(f(1) = 1\). Zero lies between them, so a root lies in \([0, 1]\).

Halve the interval. \(f(0.5) = -0.375\), so the root is in \([0.5, 1]\). \(f(0.75) = 0.172\), so it is in \([0.5, 0.75]\). \(f(0.625) = -0.131\), so it is in \([0.625, 0.75]\). Each step halves the uncertainty. Continued, the halving settles on \(0.6823\).

Common mistake

The theorem does not run backwards. Equal signs at the ends do not rule out a root. \(x^2 - 0.25\) is \(0.75\) at both \(x = -1\) and \(x = 1\), yet it is zero at \(\pm 0.5\). The theorem guarantees a root when the signs differ. It says nothing when they match.

Key

Continuous means the limit equals the value. Removable, jump, and infinite name which condition fails. On a closed interval, a continuous function takes every value between its end values.

In the Limits lab, the Hole scenario shows a removable discontinuity, with the missing value drawn as an open circle. The Jump scenario shows a filled dot on the right branch and an open one on the left.

What it leaves out

The theorem is used, not proved. Its proof needs the completeness of the real numbers, which belongs to an analysis course. The theorem also finds a root without saying how many there are.

05The precise definition

"Close enough" becomes a pair of numbers. \(\varepsilon\) is how close we demand \(f(x)\) be to \(L\). \(\delta\) is how close \(x\) must be to \(a\) to guarantee it.

\(\lim_{x \to a} f(x) = L\) means: for every \(\varepsilon \gt 0\) there is a \(\delta \gt 0\) such that

\[ 0 \lt |x - a| \lt \delta \;\Rightarrow\; |f(x) - L| \lt \varepsilon. \]

The order matters. The challenger picks \(\varepsilon\) first. We answer with a \(\delta\). A proof gives a rule that answers every \(\varepsilon\). The condition \(0 \lt |x - a|\) leaves out \(x = a\), as the informal definition did.

Why

For a line \(f(x) = mx + b\) with \(m \ne 0\), the claimed limit at \(a\) is \(L = ma + b\). The error is

\[ \begin{aligned} |f(x) - L| &= |mx + b - ma - b|\\ &= |m|\,|x - a|. \end{aligned} \]

That is less than \(\varepsilon\) exactly when \(|x - a| \lt \varepsilon/|m|\). So \(\delta = \varepsilon/|m|\) works, and no larger \(\delta\) does. A steeper line needs a narrower window.

Worked example · a delta for 3x

Take \(f(x) = 3x\) at \(a = 1\), so \(L = 3\). Demand \(\varepsilon = 0.3\). Then \(\delta = 0.3/3 = 0.1\). Check an input inside the window: \(f(1.09) = 3.27\), which is \(0.27\) from \(3\). That is inside the band.

Common mistake

A wider window fails. With \(\delta = 0.2\) for the same line, \(x = 1.15\) is allowed. Then \(f(1.15) = 3.45\), which is \(0.45\) from \(3\). That exceeds \(\varepsilon = 0.3\). Using \(\delta = \varepsilon\) for every function ignores the slope.

A curve needs one more step, because its slope changes. Bound the changing factor first by keeping \(x\) near \(a\).

Worked example · a delta for x squared

Prove \(\lim_{x \to 2} x^2 = 4\). The error factors: \(|x^2 - 4| = |x - 2|\,|x + 2|\). Agree to keep \(|x - 2| \lt 1\). Then \(1 \lt x \lt 3\), so \(|x + 2| \lt 5\). The error is less than \(5|x - 2|\). That is below \(\varepsilon\) when \(|x - 2| \lt \varepsilon/5\).

So \(\delta = \min(1, \varepsilon/5)\) works for every \(\varepsilon\). For \(\varepsilon = 0.1\), \(\delta = 0.02\). Check: \(2.02^2 = 4.0804\) and \(1.98^2 = 3.9204\). Both are within \(0.1\) of \(4\).

The largest window that works is a little wider. Solving \(x^2 = 4.1\) and \(x^2 = 3.9\) gives the edges \(2.02485\) and \(1.97484\). The tighter side is \(0.02485\). A proof needs a \(\delta\) that works, not the largest one.

The definition also proves that a limit fails. Take \(f(x) = x/|x|\) at \(0\), and choose \(\varepsilon = 1/2\). Every window around \(0\) holds a point where \(f = 1\) and a point where \(f = -1\). Those values are \(2\) apart. No single \(L\) is within \(1/2\) of both. So no \(L\) works, and the limit does not exist.

Key

\(\varepsilon\) is the demand on the output. \(\delta\) is the answer on the input. For a line, \(\delta = \varepsilon/|m|\). For a curve, first bound the factor that changes, then divide.

In the Limits lab, the ε–δ line scenario draws the band \(L \pm \varepsilon\) and the window \(a \pm \delta\). The readout's \(\delta\) is \(\varepsilon/|m|\). A bisection that tests the inequality directly finds the same number.

What it leaves out

The one-sided and infinite versions of the definition change only the conditions: one side of \(a\), or "\(f(x) \gt M\)" in place of the \(\varepsilon\) band. They are in §2.5 of the text. The same idea for sequences, with \(N\) in place of \(\delta\), opens Calculus II.

06The derivative as a limit

A secant line joins two points on a graph. Through \((a, f(a))\) and \((a + h, f(a + h))\), its slope is the difference quotient. As \(h\) shrinks, the second point slides toward the first. The secant turns into the tangent line, if the slopes settle on a limit.

\[ f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}. \]

When the limit exists, \(f\) is differentiable at \(a\). The tangent line at \(a\) is the line through \((a, f(a))\) with that slope: \(y = f(a) + f'(a)(x - a)\).

Worked example · a shrinking secant

Take \(f(x) = x^2\) at \(a = 1\). The quotient is \(((1 + h)^2 - 1)/h = (2h + h^2)/h = 2 + h\), for \(h \ne 0\). With \(h = 0.4\) the secant slope is \(2.4\). With \(h = 0.1\) it is \(2.1\). With \(h = 0.01\) it is \(2.01\). The limit is \(2\), so \(f'(1) = 2\).

Letting \(a\) vary makes \(f'\) a function. For \(x^2\) the same algebra at a general \(x\) gives \(2x + h\), so \(f'(x) = 2x\). Other names for it are \(dy/dx\) and \(\tfrac{d}{dx}f(x)\). Differentiating again gives \(f''\), the rate at which the slope changes.

Why

A differentiable function is continuous. Write the change in \(f\) as a product, for \(h \ne 0\):

\[ f(a + h) - f(a) = h \cdot \frac{f(a + h) - f(a)}{h}. \]

As \(h \to 0\), the first factor goes to \(0\) and the second to \(f'(a)\). The product goes to \(0 \cdot f'(a) = 0\). So \(f(a + h) \to f(a)\), which is continuity at \(a\).

The converse fails. A corner is continuous but has no tangent.

Worked example · a corner

Take \(f(x) = |x|\) at \(0\). For \(h \gt 0\) the quotient is \(|h|/h = 1\). For \(h \lt 0\) it is \(-1\). The one-sided limits of the quotient are \(-1\) and \(1\). They disagree, so \(f'(0)\) does not exist. Yet \(|x|\) is continuous at \(0\).

Common mistake

A secant slope with a small \(h\) is an estimate, not the derivative. For \(x^2\) at \(1\), \(h = 0.1\) gives \(2.1\), which is off by \(h\) itself. Report the limit, not the last quotient you computed.

Key

\(f'(a)\) is the limit of secant slopes. Differentiable implies continuous. Continuous does not imply differentiable.

In the Secant lab, slide \(h\) toward zero. The secant slope in the readout approaches \(f'(x_0)\), which the lab also computes by a second route.

What it leaves out

A function can also fail to be differentiable at a vertical tangent, such as \(\sqrt[3]{x}\) at \(0\), where the quotient grows without bound. This section shows only the corner.

07Power, product, and quotient rules

The limit definition is slow. A few rules, each proved once from it, do almost every derivative in the course.

A constant has derivative \(0\): its difference quotient is \(0/h\). The derivative of \(x\) is \(1\). Sums and constant multiples pass straight through, because the limit laws do.

Why

For a positive whole number \(n\), expand \((x + h)^n\) with the binomial theorem:

\[ \begin{aligned} (x + h)^n &= x^n + n x^{n-1} h\\ &\quad + (\text{terms with } h^2, h^3, \ldots). \end{aligned} \]

Subtract \(x^n\) and divide by \(h\). Every remaining term but \(n x^{n-1}\) still holds a factor of \(h\). Let \(h \to 0\). Section 12 extends the rule to every real exponent.

\[ \frac{d}{dx} x^n = n x^{n-1}. \]
Worked example · secant on a cubic

For \(f(x) = x^3\), the power rule gives \(f'(1) = 3\). Check against the definition. The quotient is \(((1 + h)^3 - 1)/h = 3 + 3h + h^2\). At \(h = 0.4\) that is \(4.36\). At \(h = 0.1\) it is \(3.31\). The limit is \(3\).

A product needs its own rule. The derivative of a product is not the product of the derivatives.

Why

Add and subtract \(f(x + h)g(x)\) in the top of the quotient:

\[ \begin{aligned} &\frac{f(x+h)g(x+h) - f(x)g(x)}{h}\\ &\quad = f(x+h)\,\frac{g(x+h) - g(x)}{h}\\ &\qquad + g(x)\,\frac{f(x+h) - f(x)}{h}. \end{aligned} \]

Let \(h \to 0\). \(f(x + h) \to f(x)\), because \(f\) is differentiable and so continuous. The quotients become \(g'\) and \(f'\).

\[ (fg)' = f'g + fg', \qquad \left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}. \]

The quotient rule follows from the product rule. Write \(q = f/g\), so \(f = qg\). Then \(f' = q'g + qg'\). Solve for \(q'\), and replace \(q\) by \(f/g\).

Worked example · a product

Let \(f(x) = x^2(3x + 1)\). Take \(u = x^2\) and \(v = 3x + 1\). Then \(f' = 2x(3x + 1) + 3x^2\). At \(x = 2\): \(4 \cdot 7 + 12 = 40\).

Check by expanding first. \(f(x) = 3x^3 + x^2\), so \(f'(x) = 9x^2 + 2x\). At \(2\): \(36 + 4 = 40\).

Worked example · a quotient

Let \(f(x) = x^2/(x + 1)\). The rule gives \(f' = (2x(x + 1) - x^2)/(x + 1)^2\). At \(x = 1\): \((4 - 1)/4 = 0.75\).

Common mistake

\((fg)' \ne f'g'\). For \(x^2(3x + 1)\) at \(2\), the product of the derivatives is \(2x \cdot 3 = 12\). The true derivative is \(40\). In the quotient rule, the order on top matters: \(f'g - fg'\), not the reverse, which flips the sign.

Key

Power rule: bring the exponent down and lower it by one. Product rule: differentiate one factor at a time and add. Quotient rule: bottom times top-prime, minus top times bottom-prime, over the bottom squared.

In the Secant lab, the \(x^3\) scenario shows the secant slope above \(3\) at \(x_0 = 1\). It falls toward \(3\) as \(h\) shrinks.

What it leaves out

The power rule is proved here only for whole-number exponents. Negative and fractional exponents, such as \(x^{-1}\) and \(\sqrt{x}\), wait for logarithmic differentiation in Section 12.

08Rates of change on a line

A derivative is a rate. If \(s(t)\) is a position on a line at time \(t\), then \(v(t) = s'(t)\) is the velocity, and \(a(t) = v'(t) = s''(t)\) is the acceleration. The sign of \(v\) gives the direction. Speed is \(|v|\).

Why

The average velocity over \([t, t + h]\) is \((s(t + h) - s(t))/h\): distance moved over time taken. That is the difference quotient of \(s\). Its limit as \(h \to 0\) is the instantaneous velocity. The same argument, applied to \(v\), gives acceleration.

Worked example · a particle that turns back

Let \(s(t) = t^3 - 6t^2 + 9t\), in metres, for \(0 \le t \le 4\) seconds. Then \(v(t) = 3t^2 - 12t + 9 = 3(t - 1)(t - 3)\), and \(a(t) = 6t - 12\).

The particle stops at \(t = 1\) and \(t = 3\). It moves forward on \([0, 1)\), back on \((1, 3)\), and forward again after \(3\). The positions are \(s(0) = 0\), \(s(1) = 4\), \(s(3) = 0\), and \(s(4) = 4\).

The distance travelled is \(4 + 4 + 4 = 12\) m. The displacement is \(s(4) - s(0) = 4\) m. At \(t = 2\) the velocity is \(-3\) m/s and the acceleration is \(0\).

Common mistake

Distance is not \(|s(4) - s(0)|\) when the particle turns back. Here that gives \(4\) m and misses \(8\) m of travel. Find where \(v = 0\), split the interval there, and add the lengths of the pieces.

Key

\(v = s'\) and \(a = v'\). The particle turns where \(v\) changes sign. Distance adds the pieces between turns.

The same reading applies outside motion. A marginal cost is the derivative of cost with respect to quantity. A growth rate is the derivative of a population with respect to time.

What it leaves out

This section starts from a known \(s(t)\). Going the other way, from \(v(t)\) back to \(s(t)\), is integration, in Unit 4. Why a body has a particular acceleration is a question about force. That belongs to physics.

09Sine and cosine

The two trigonometric limits from Unit 1 are exactly what the derivative of sine needs.

Why

Use the angle-sum formula, \(\sin(x + h) = \sin x \cos h + \cos x \sin h\). The difference quotient becomes

\[ \begin{aligned} &\frac{\sin(x + h) - \sin x}{h}\\ &\quad = \sin x \cdot \frac{\cos h - 1}{h} + \cos x \cdot \frac{\sin h}{h}. \end{aligned} \]

As \(h \to 0\), the first fraction goes to \(0\) and the second to \(1\). What is left is \(\cos x\). The same steps with \(\cos(x + h) = \cos x \cos h - \sin x \sin h\) give \(-\sin x\).

\[ \begin{aligned} \frac{d}{dx}\sin x &= \cos x,\\ \frac{d}{dx}\cos x &= -\sin x,\\ \frac{d}{dx}\tan x &= \sec^2 x. \end{aligned} \]

The tangent follows from the quotient rule. \(\tan x = \sin x / \cos x\), so its derivative is \((\cos^2 x + \sin^2 x)/\cos^2 x = 1/\cos^2 x\).

Worked example · the slope of sine at π/3

The rule gives \(\cos(\pi/3) = 0.5\). The secant slopes from \(x_0 = \pi/3\) approach it from below: \(0.316\) at \(h = 0.4\), \(0.456\) at \(h = 0.1\), and \(0.478\) at \(h = 0.05\). Sine bends downward here, so each secant runs under the tangent.

Common mistake

The rule needs radians. Measured in degrees, \(\sin(x^\circ) = \sin(\pi x/180)\), and its derivative is \((\pi/180)\cos(x^\circ)\). That extra factor is \(0.01745\). Leaving a calculator in degree mode scales every slope by it.

Key

Sine's derivative is cosine. Cosine's derivative is minus sine. Both depend on the limit \(\sin h / h \to 1\), which holds in radians.

In the Secant lab, the sin x scenario puts the tangent and the secant on the same curve. At the top of a hump the tangent is flat and \(f'(x_0) = 0\).

What it leaves out

The other three functions, secant, cosecant, and cotangent, follow from the quotient rule and are listed in §3.5 of the text. They are not derived again here.

10The chain rule

A composition \(y = f(g(x))\) changes because \(g\) changes, and \(f\) responds to that change. The rates multiply.

\[ \frac{d}{dx} f(g(x)) = f'(g(x))\, g'(x). \]

In Leibniz notation, with \(u = g(x)\):

\[ \frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}. \]
Why

Let \(u = g(x)\). A step \(\Delta x\) changes \(u\) by \(\Delta u\), and that changes \(y\) by \(\Delta y\). When \(\Delta u \ne 0\),

\[ \frac{\Delta y}{\Delta x} = \frac{\Delta y}{\Delta u}\cdot\frac{\Delta u}{\Delta x}. \]

As \(\Delta x \to 0\), \(\Delta u \to 0\) too, because \(g\) is continuous. The two factors become \(f'(u)\) and \(g'(x)\). The case where \(\Delta u = 0\) for small steps needs a separate argument. The text gives it in §3.6, and the rule still holds.

Worked example · a power of a line

Let \(f(x) = (2x + 1)^3\). The outside is \(u^3\), with derivative \(3u^2\). The inside is \(u = 2x + 1\), with derivative \(2\). So \(f'(x) = 3(2x + 1)^2 \cdot 2 = 6(2x + 1)^2\). At \(x = 1\): \(6 \cdot 9 = 54\).

Worked example · sine of a square

Let \(f(x) = \sin(x^2)\). The outside is \(\sin u\), the inside \(u = x^2\). So \(f'(x) = \cos(x^2) \cdot 2x\). At \(x = \sqrt{\pi}\), \(\cos\pi = -1\), and \(f' = -2\sqrt{\pi} = -3.545\).

Common mistake

Dropping the inner derivative. For \((2x + 1)^3\) at \(1\), writing only \(3(2x + 1)^2\) gives \(27\). The true value is \(54\). The factor \(2\) is how fast the inside changes, and it multiplies everything.

Key

Differentiate the outside, leave the inside alone, then multiply by the derivative of the inside. For a chain of three, multiply three rates.

What it leaves out

The \(\Delta u = 0\) case of the proof is only named here. Chains of partial derivatives, where the inside has several variables, come in Calculus III.

11Implicit differentiation

Some curves are not graphs of one function. The circle \(x^2 + y^2 = 25\) has two \(y\) values for most \(x\). Near a single point, though, it is a graph. Treat \(y\) as an unknown function of \(x\) there, and differentiate both sides of the equation with the chain rule.

Worked example · a slope on a circle

Differentiate \(x^2 + y^2 = 25\) in \(x\). The term \(y^2\) gives \(2y\,y'\) by the chain rule. So \(2x + 2y\,y' = 0\), and \(y' = -x/y\). At \((3, 4)\) the slope is \(-3/4 = -0.75\).

Check with the upper half written out: \(y = \sqrt{25 - x^2}\), so \(y' = -x/\sqrt{25 - x^2}\). At \(x = 3\): \(-3/4\).

Key

Differentiate every occurrence of y through the chain rule. Solve for y′ only after differentiating the whole constraint.

What the model leaves out

The formula \(y'=-x/y\) assumes y is nonzero. At the circle's left and right ends the tangent is vertical, so y cannot be represented there by a differentiable function of x.

12Inverses, exponentials, and logarithms

If \(f\) has an inverse, the inverse's slope is the reciprocal of \(f\)'s slope at the matching point. Reflecting a graph in \(y = x\) swaps rise and run.

Why

Differentiate \(f(f^{-1}(x)) = x\) with the chain rule: \(f'(f^{-1}(x)) \cdot (f^{-1})'(x) = 1\). Divide.

\[ (f^{-1})'(x) = \frac{1}{f'(f^{-1}(x))}. \]

For \(\arcsin x\): \(y = \arcsin x\) means \(\sin y = x\). Then \(\cos y \cdot y' = 1\), and \(\cos y = \sqrt{1 - x^2}\) on the arcsine's range. So \((\arcsin x)' = 1/\sqrt{1 - x^2}\).

Worked example · the slope of arcsine at 1/2

\((\arcsin)'(0.5) = 1/\sqrt{0.75} = 1.1547\). A centred difference with step \(0.0001\) gives the same four figures.

For an exponential \(a^x\), the difference quotient factors: \((a^{x+h} - a^x)/h = a^x \cdot (a^h - 1)/h\). So the derivative is \(a^x\) times the constant \(\lim (a^h - 1)/h\). For \(a = 2\) that constant is \(0.693\). For \(a = 3\) it is \(1.099\). The base where it equals exactly \(1\) is \(e = 2.71828\ldots\).

\[ \begin{aligned} \frac{d}{dx} e^x &= e^x,\\ \frac{d}{dx} \ln x &= \frac{1}{x},\\ \frac{d}{dx} a^x &= a^x \ln a. \end{aligned} \]
Why

Let \(y = \ln x\), so \(e^y = x\). Differentiate: \(e^y y' = 1\), so \(y' = 1/e^y = 1/x\). For \(a^x\), write \(a^x = e^{x\ln a}\), and the chain rule gives the factor \(\ln a\). That explains the constants above: \(\ln 2 = 0.693\) and \(\ln 3 = 1.099\).

Logarithmic differentiation finishes the power rule. Let \(y = x^n\) for any real \(n\) and \(x \gt 0\). Then \(\ln y = n\ln x\). Differentiate: \(y'/y = n/x\). So \(y' = n x^{n-1}\), for every real exponent.

Worked example · x to the x

Let \(y = x^x\) for \(x \gt 0\). Then \(\ln y = x\ln x\). Differentiate: \(y'/y = \ln x + 1\). So \(y' = x^x(\ln x + 1)\). At \(x = 2\): \(4(0.6931 + 1) = 6.773\). A centred difference agrees to four figures.

Common mistake

\(x^x\) is neither a power nor an exponential. The power rule alone gives \(x \cdot x^{x-1}\), which is \(4\) at \(x = 2\). The exponential rule alone gives \(x^x\ln x\), which is \(2.773\). The true derivative is their sum, \(6.773\). Both the base and the exponent vary.

Key

An inverse's slope is the reciprocal of the original slope at the matching point. \(e^x\) is its own derivative. \(\ln x\) has derivative \(1/x\). When a variable sits in an exponent, take logarithms first.

What it leaves out

This section assumes that \(e\) exists: a base with \(\lim (e^h - 1)/h = 1\). The text defines \(e\) through a limit and makes that precise. Hyperbolic functions, also in Chapter 3, are not covered.
