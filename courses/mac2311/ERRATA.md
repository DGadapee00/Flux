# Checked source corrections

## 18.01SC, Fall 2010, Unit 3 exercises, solution 3B-3(a), PDF page 4

[Published solutions](https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/resources/mit18_01sc_pset3sol/).

The displayed sums use four equal strips for x³ on [0,1]. Their printed simplified
fractions, 15/128 for the right sum and 7/128 for the left sum, do not equal those sums.

- Right: (1 + 8 + 27 + 64) / 256 = 25/64 = 0.390625.
- Left: (0 + 1 + 8 + 27) / 256 = 9/64 = 0.140625.

The exact integral is 1/4 and lies between the corrected sums. Their difference is
1/4, matching the telescoping endpoint formula (f(1)−f(0))/4. The bank, real lab and
notes independently check these corrected values. The notes label this a correction
to the source, rather than a student mistake. No source text or figures are copied.
