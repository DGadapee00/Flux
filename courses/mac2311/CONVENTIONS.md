# Calculus I and II conventions

- Follow 18.01SC's order, supplemented by OpenStax Calculus Volumes 1 and 2 (D28).
- The course ID stays `mac2311`; the header code is MAC 2311–2312.
- Canonical unit IDs are `c1`–`c6`. Old `u1`–`u4` identifiers always mean legacy links.
- Calculus I problem IDs are retained; Calculus II IDs use the `ii.` prefix.
- Seed generation uses the original template ID to preserve saved questions.
- Chapters without a prefix name Volume 1. `v2.2`, `v2.3`, `v2.5`, `v2.6`, `v2.7` name Volume 2.
- The geometric and numerical answers stay in their original units and conventions.
- Generated teaching numbers are verification cases, not newly verified printed answers.
- Notes use the shared shell's parts, legend, worked examples and model-limit boxes.
- `flux.mac2312.*` keys are retained for compatibility and old hub backups.
