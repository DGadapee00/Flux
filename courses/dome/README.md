# Tank dome

A project course in Flux's standard shell, with four units, four independently checked labs,
notes for all eleven shop stations and generated numeric practice. Shop-floor judgement cases
are worked examples in the notes. The geometry and machine illustrations are teaching models.

Run `npm run dev -w @flux/dome` from the repo root. `npm test -w @flux/dome` checks the models,
practice, notes and routes. See `PROVENANCE.md` for source details and model limits.

The former standalone traveler is archived under
`docs/history/project-guides-2026-11-10/course-pages/courses/dome/`.
