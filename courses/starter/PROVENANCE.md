# Provenance

STARTER is an example course. It is not deployed and is not in the hub. Copy it to start a new
course (`.claude/skills/flux-new-course`), then replace this file.

A real course's PROVENANCE.md says, in this order of authority (DECISIONS.md, D23):

1. **The OCW program:** course number, title, term, URL and licence (CC BY-NC-SA 4.0). Nothing is
   copied; worked cases cite course, term, problem set and problem.
2. **The textbook:** title, author, licence, and that it is cited by section only through
   `src/data/textbook.js`.
3. **Any UNF syllabus or course pack:** what it was used for (exam dates, exam style, topics OCW
   lacks), and that nothing from it ships unless the instructor agrees in writing.

The example content here (a tank that fills and drains) is written for this file and cites nothing.
